# AI 수업 설계 연수 사이트

cap89 스타일과 Lucian UX/UI 요소로 만든 연수 안내·신청 사이트입니다.

- **프론트엔드**: 이 저장소의 `index.html` 한 장. GitHub에 올리면 Vercel이 자동으로 배포합니다.
- **백엔드·데이터베이스**: 구글 스프레드시트 '연수 관리' + Apps Script(`apps-script/Code.gs`).
  사이트 문구, 설정, 신청 내역이 모두 시트에 저장됩니다.

## 처음 한 번 설정하기

### 1. 시트에 Apps Script 붙이기
1. '연수 관리' 시트를 엽니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 누릅니다.
3. 편집기에 있는 내용을 모두 지우고 `apps-script/Code.gs`의 내용을 통째로 붙여 넣은 뒤 저장(💾)합니다.
4. 위쪽 함수 목록에서 **setup**을 고르고 **실행**을 누릅니다.
   - 처음에는 권한 승인 창이 뜹니다. 본인 계정을 고르고 "고급 → (안전하지 않음)으로 이동 → 허용"을 누르세요. 본인이 만든 스크립트라 나오는 안내입니다.
5. 시트로 돌아가면 **Settings, 내용, 특징, 주차, 세부과정, FAQ, 후기, 신청** 탭이 생겨 있습니다.
   관리자 비밀번호는 **Settings 탭의 adminPassword** 칸에 있어요. 원하는 값으로 바꿔도 됩니다.

### 2. 웹 앱으로 배포하기
1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴(⚙️) → **웹 앱**을 고릅니다.
3. 다음처럼 설정합니다.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> "모든 사용자"로 해야 방문자가 내용을 보고 신청할 수 있어요. 시트 자체는 공개되지 않습니다.
> 사이트는 이 주소를 통해 필요한 내용만 주고받고, 신청 내역은 관리자 비밀번호가 있어야 볼 수 있어요.

### 3. 사이트에 주소 넣기
`index.html`에서 아래 한 줄을 찾아 따옴표 안에 웹 앱 URL을 넣고 저장(커밋)하면 Vercel이 다시 배포합니다.

```js
var API_URL = '';
```

## 관리자 사용법
- 사이트 맨 아래 **🔒 관리자** → Settings 탭의 비밀번호로 로그인합니다.
- 로그인하면 각 영역 오른쪽 위에 **✏️ 버튼**이 생깁니다. 눌러서 고치고 **저장하기**를 누르면 시트에 바로 저장됩니다.
- 아래쪽 검은 막대에서 **📋 신청 관리**(상태·메모 변경, 검색), **⚙️ 사이트 설정**(제목, 로고, 비밀번호 변경)을 엽니다.
- 시트에서 직접 고쳐도 됩니다. 사이트를 새로고침하면 반영돼요.

## Apps Script 코드를 고친 뒤에는
**배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포**를 눌러야 바뀐 코드가 적용됩니다.
"새 배포"를 다시 하면 주소가 바뀌니 주의하세요.
