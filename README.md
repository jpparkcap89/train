# 연수 안내·신청 사이트 (누적 관리형)

연수가 열릴 때마다 같은 사이트에서 새 연수로 바꿔 가며 쓰고, 신청·이수 기록은 계속 쌓이는 사이트입니다.

- **프론트엔드**: 이 저장소의 `index.html` 한 장. GitHub에 올리면 Vercel이 자동으로 배포합니다.
- **백엔드·데이터베이스**: 구글 스프레드시트 '연수 관리' + Apps Script(`apps-script/Code.gs`)

## 데이터 구조 (시트 탭)

| 탭 | 한 줄 = | 메모 |
|---|---|---|
| Settings | 설정 1개 | 관리자 비밀번호(adminPassword), 대표 연수(currentCourse) 등 |
| 연수 | 연수 1개 | 연수 ID로 구분. 상태: 준비 · 모집중 · 마감 · 종료 |
| 회차 | 회차 1개 | 연수 ID별 |
| 세부과정 | 주제 탭의 한 줄 | 연수 ID별 |
| 특징 | 특징 카드 1개 | 연수 ID를 비우면 모든 연수 공통 |
| FAQ | 질문 1개 | 연수 ID를 비우면 모든 연수 공통 |
| 후기 | 후기 1개 | 연수 ID별. 노출=예인 것만 사이트에 표시 |
| 신청 | 신청 1건 | 연수 ID, 상태(접수·확정·대기·취소), 이수(이수·미이수) |
| 참가자 | 선생님 1명 | 학교 메일 기준 신청·확정·이수 횟수. 자동 계산되니 직접 고치지 마세요 |

1행의 열 제목은 바꾸지 마세요. 열 순서는 바꿔도 됩니다.

## 처음 한 번 설정하기

### 1. 시트에 Apps Script 붙이기
1. '연수 관리' 시트를 엽니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 누릅니다.
3. 편집기 내용을 모두 지우고 `apps-script/Code.gs`를 통째로 붙여 넣은 뒤 저장(💾)합니다.
4. 함수 목록에서 **setup**을 고르고 **실행**합니다.
   - 처음에는 권한 승인 창이 떠요. 본인 계정 → "고급 → (안전하지 않음)으로 이동 → 허용"을 누르세요. 본인이 만든 스크립트라 나오는 안내입니다.
5. 시트에 위 탭들이 생기고, 예시 연수(2027-W01)가 채워집니다. 관리자 비밀번호는 **Settings 탭의 adminPassword**에 있어요.

### 2. 웹 앱으로 배포하기
1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포** → 톱니바퀴(⚙️) → **웹 앱**
2. 실행 사용자: **나** / 액세스 권한이 있는 사용자: **모든 사용자**
3. **배포** 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 시트 자체는 공개되지 않아요. 방문자는 이 주소로 공개 내용만 받고, 신청 내역과 편집은 관리자 비밀번호가 있어야 합니다.

### 3. 사이트에 주소 넣기
`index.html`의 `var API_URL = '';` 따옴표 안에 웹 앱 URL을 넣고 커밋하면 Vercel이 다시 배포합니다.

## 관리자 사용법
- 맨 아래 **🔒 관리자** → 비밀번호로 로그인하면 아래쪽에 관리자 막대가 생깁니다.
- **✏️ 버튼**: 각 영역 오른쪽 위. 고치고 저장하면 지금 보고 있는 연수에 저장돼요.
- **📚 연수 관리**: 연수 목록(신청·이수 인원)과 **＋ 새 연수 시작**.
  - 개요(연수 ID, 연수명, 제목, 기간, 정원, 신청 기간 등)부터 입력합니다.
  - 시작하면 지금 연수는 **종료**되어 **지난 연수**로 보관되고, 새 연수가 첫 화면에 나와요.
  - "회차·세부과정 가져오기"를 체크하면 이전 연수의 회차를 복사해 고쳐 쓸 수 있어요.
  - 시작 상태를 **준비**로 두면 방문자에게는 "다음 연수 준비 중" 화면이 보이고, 관리자만 내용을 미리 채울 수 있어요. 다 되면 ✏️ 연수 신청 → 진행 상태를 **모집중**으로 바꾸세요.
- **📋 신청 관리**: 연수별 또는 모든 연수의 신청자 보기, 상태·이수·메모 변경, 검색.
  - 스마트폰: 전화번호 옆 📞 전화 걸기, 💬 문자 보내기
  - 맥: 💬 문자 보내기 (메시지 앱으로 열려요)
- **⚙️ 사이트 설정**: 사이트 이름, 로고, 문의처, 알림 메일, 관리자 비밀번호 변경

## 방문자에게 보이는 것
- 첫 화면: 대표 연수 (Settings의 currentCourse)
- **지난 연수** 메뉴: 종료된 연수의 개요, 회차, 후기
- 특정 연수 주소: `사이트주소/?c=연수ID`

## 신청 규칙
- 신청은 연수 상태가 **모집중**이고, 신청 시작일~마감일 사이일 때만 받아요.
- 정원이 차면 새 신청은 **대기**로 접수됩니다.
- 같은 연수에 같은 학교 메일로 두 번 신청할 수 없어요.
- 전화번호는 숫자만 입력하면 `010-1234-5678` 형식으로 저장됩니다.

## Apps Script 코드를 고친 뒤에는
**배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 눌러야 적용돼요. "새 배포"를 다시 하면 주소가 바뀝니다.
